# EV Charging Demand Forecasting

Built a Linear Regression model to predict EV energy demand with 81.70% accuracy.

### Tools: Python, Pandas, Matplotlib, Scikit-Learn

### Key Findings:
- Peak Demand: 8-9 AM & 6-8 PM
- Features used: temperature, traffic_flow, charging_price, hour
- Business Use: Helps to plan charger installation & dynamic pricing
